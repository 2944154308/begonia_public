# Fourth Service - 精密体检页面图片资源

本目录存放精密体检（Health Checkup）页面的相关图片资源。

## 所需图片清单

### 1. 图标文件（建议 100x100px PNG）

- `efficiency.png` - 超高检出效率图标（红色靶心图标）
- `technology.png` - 顶尖筛查技术图标（显微镜图标）
- `service.png` - 严谨服务理念图标（红色爱心图标）
- `professional.png` - 医疗级专业保障图标（粉色医疗图标）
- `comprehensive.png` - 项目全面筛查图标（黄色列表图标）
- `early-detection.png` - 超高早癌检出率图标（粉色盾牌图标）
- `high-net-worth.png` - 追求品质的高净值人群图标（金色钻石图标）
- `middle-aged.png` - 40岁以上中老年群体图标（黄色日历图标）
- `special-risk.png` - 特殊风险与备孕人群图标（粉色双人图标）

### 2. 说明

所有图标应保持统一的视觉风格，建议使用扁平化设计，颜色与项目主题色（粉色系）协调。
