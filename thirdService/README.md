## Image Style Guidelines

- Images should have rounded corners (will be applied via CSS)
- Maintain consistent aspect ratio across all three medical extension images
- High resolution recommended for better visual quality
- Medical extension images will be displayed at `w-full h-48 object-cover`
- Lifestyle hero image will be displayed at `w-full h-96 object-cover`
- Icons should have transparent backgrounds and be sized appropriately
